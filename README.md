# Amazon_Books_project
Sentiment classification on Amazon Book Reviews using TF-IDF+XGBoost, fine-tuned DistilBERT, and LLM API — with EDA, imbalanced learning, and business insights.

This project demonstrates: 
(1) feature engineering for NLP tasks on real-world, messy data; 
(2) a comparison of classical ML, fine-tuned transformer, and LLM API approaches to classification; 
(3) handling imbalanced classes; 
(4) business-oriented interpretation of results — core skills expected in modern Data Scientist roles across fintech, product, and data-driven companies.
